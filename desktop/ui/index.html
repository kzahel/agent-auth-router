Account setup

Install Claude Code or Codex first. Sign in opens your chosen terminal with the selected profile. Choose Terminal.app or the built-in terminal in App settings. Choose a login method there and follow the official CLI prompts. Enrolling an account does not grant an integration access.

Add account checks the profile automatically. Check profile is an optional preview. Enrollment leaves its files and permissions unchanged. Sign in only if needed; CLI sign-in and renewal can update its credentials.
